      What this evaluates

      The parent opens an explicit layout envelope, with no tube or endcap geometry. Opening the core requests its exact display parts. Only choosing a native workspace loads SolidCraft; only editing a leaf requests that leaf’s authoring file.

      Native links retain finished bodies. The parent links the envelope; the exact core links a tube and repeated endcap joined at their named faces. Envelope dimensions follow the exact core’s published exterior bounds. Changes to an internal cap can leave the parent envelope unchanged.

      An opened native workspace loads its embedded finished bodies together. Native linking skips child histories; it does not provide streaming of individual bodies inside that saved representation.

      The envelope supplies exterior layout bounds. Exact fit, mass, cut and print work uses the core or leaf design.

      Repeating this simple core tests shared definitions and the loading boundary. It does not establish the performance of the complete enclosure’s geometry.

      This study includes the barrel and recessed endcap blanks. Fluid ports, rod registers, welds, fittings and the cold-core casing belong outside this example.
