# Lite enclosure assembly

The [enclosure shell](../enclosure/) wrapped around the
[enclosure contents](../enclosure-contents-assembly/) in their shared
coordinates. The whole Lite Edition as one model: a translucent PETG box and
everything inside it.

The contents keep their per-part colors from the contents assembly; the shell
is translucent so the arrangement reads through it.

## Regenerate

`tools/cad-venv/bin/python pie-in-the-sky/lite/enclosure-assembly/enclosure_assembly.py`
→ `enclosure-assembly.step`.
