# Source comments

Omit comments that narrate the next few lines. If a comment gives an operation a
better name, use that name in the code. Express constraints in types or calculations
where possible. Keep each piece of machinery’s one-line purpose at its definition.

Before adding a tag, name the tool that reads it and what the tag enables.
Preserve it when editing the producer. [Model and slice examples](../tools/hsm/inspection/README.md#annotations-in-the-model-and-slice).

## Clearance and fit

For fit or dimension claims, [match the question to the bench record, geometry measurement or Git history](../hardware/ledger/fitted.md#evidence-for-a-fit-claim).
