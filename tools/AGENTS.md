# Project tools

- The [print build](hsm/print-build/README.md) publishes completed parts. For comparisons,
  handoffs, benchmarks and cleanup, follow [Temporary build files](hsm/repo-tools/README.md#temporary-build-files).
- For a requested timing, use the [request-to-view measurement](iteration/README.md).
  Reopen [build speed work](hsm/conversion.md#speed-work) when a measured request shows the build was the long part.
- For inline HTML in chat, use the [mobile compatibility skill](viz/inline-mobile/SKILL.md)
  alongside the host visualization instructions. For print playback, start with
  [`hsm-gcode view playback --inline`](gcode/README.md#print-playback).
