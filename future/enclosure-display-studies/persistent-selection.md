# Persistent flavor selection

[`persistent-selection.html`](persistent-selection.html) contains four visual variations of
Control room: Porcelain, Tangerine, Letterpress and Console. Each includes Home, Adjust, Fill,
Prime and Clean. The initial view is Fill.

## What remains visible

Both flavor images occupy fixed positions in the left column. A selection treatment identifies
the active flavor. A second, larger copy of that flavor's image occupies the adjacent column.
The controls act on the flavor shown there.

Changing the action changes the controls area. Both small flavor images and the large selected
image remain visible in their existing positions. Selecting the other flavor updates the
selection treatment, large image and action target together; the current action page stays open.
The faucet preview follows the same selection.

The same arrangement remains visible during an operation. Stop ends a running Fill or Clean
before the target can change; Prime runs while held. The mockups operate locally.

## Variations

| Direction | Treatment |
| --- | --- |
| Porcelain | Pale blue and white, soft image framing, compact task bar, rounded controls |
| Tangerine | Amber and rust, broad type, rounded action button, navigation below the controls |
| Letterpress | Burgundy and paper, serif headings, ruled home actions, dedicated action pane |
| Console | Cobalt and orange, rectangular controls, persistent top tabs, broad action button |

All four use the full portrait artwork from the [logo studies](README.md#the-image-as-identity).
The functional basis and artwork sources are in that study's [basis and scope](README.md#basis-and-scope).

## Visual review

The review covers all five pages, both selections, and running operation states. The three
image rectangles have identical coordinates across each direction's page and operation states.
Both flavor selectors retain their order when selection changes. The selected thumbnail,
large image and faucet preview agree. Render checks cover bounds, image loading and minimum
44-pixel action targets at the enclosure's 800 × 480 resolution.
