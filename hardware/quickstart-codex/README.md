# Quick start · Codex

One 19 × 13 inch landscape sheet with six illustrated installation steps, preparation at the
top and the first-glass sequence below. Print at 100% on 13 × 19 inch paper.

The PDF, cover, fonts and artwork are committed snapshots. The manual authoring script is
`tools/quickstart-codex/build.py`; it is outside the hardware build. The quick start, install
guide and weld rotator guide are the source material for this edition.
