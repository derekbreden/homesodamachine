# Shared print utilities

`petgf_cooling.rs` and `support_audit.rs` supply the native print-preparation commands.
[Print preparation](/tools/hsm/print-prep/README.md) describes their entrypoints.

The native [fit catalog](/tools/hsm/catalog/src/lib.rs) reads the authored allowances in
[scalars.json](/tools/hsm/shared-data/catalog/scalars.json).
The enclosure [skin](/hardware/printed-parts/enclosure/enclosure/solid/skin.rs) defines its
show surface. [Flute photographs](flute-evidence/README.md) record the physical appearance.
