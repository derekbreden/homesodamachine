# Printed parts

Use the part’s recipe for a production print. See [faucet plates and finish trials](faucet/AGENTS.md)
or [printable enclosure pieces](enclosure/AGENTS.md) when working on those parts.

## Preparing and sending a plate

Follow [bed placement](../../tools/bambu-printers.md#placement-on-unseasoned-plates) for layout.
Check [printer readiness and startup spacing](../../tools/bambu-printers.md#print-submission) before a send or resume.

## Shape

When designing a solid, follow the [printed part shape rules](../design-pressures.md#printed-part-shape).
For fit trials, use the [production print conditions](../printing-the-machine/README.md#comparing-fits).

## Publish loop

For a changed solid, follow the [publication and STL review procedure](../../tools/hsm/print-build/README.md#publishing-a-changed-part).

## What each file shows

For a viewer pick, compare the [authored, printed and drawn surfaces](../../tools/hsm/inspection/README.md#reading-a-surface).

## Supports

Leave removal access for branching trees in enclosed cavities. Check each painted
underside’s first deposited courses for contact and each bridge for two landings.
When preparing a PET-GF plate, use the [support recipe](petgf-supports.md) and [cooling policy](cooling/README.md).
