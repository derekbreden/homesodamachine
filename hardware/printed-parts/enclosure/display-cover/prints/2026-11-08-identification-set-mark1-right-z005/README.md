# Identification set with right-side clearance trim

The [review](review.json) records the requested right-side clearance trial on
Mark One's glued Engineering Plate. Filament start hooks apply the right-side
trim and retain the left-side baseline. Filament end hooks clear the trim before
maintenance and tool changes. The geometry, extrusion paths and remaining
settings match the reviewed identification set.

The editable project and sliced archive are retained beside the review. The
[preceding physical result](../2026-11-08-identification-set-mark1-dried-rethreaded/physical-result.json)
records the failure after drying and rethreading.

The [launch record](launch.json) identifies the accepted job, checked material
slots, selected hotends and calibration options.

The [physical result](physical-result.json) records Derek's acceptance of the
finished multicolor appearance and visual nozzle registration. The chips fit
tightly between the enclosure rails; the linked width trials address that fit.
