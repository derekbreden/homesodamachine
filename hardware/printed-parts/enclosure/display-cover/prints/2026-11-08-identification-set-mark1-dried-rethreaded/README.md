# Identification set after drying and rethreading

The [review](review.json) identifies the unchanged identification-set archive,
material mapping and launch options for the glued Engineering Plate. The
[closed-AMS baseline](../2026-11-07-identification-set-mark1-white-spare/drying/closed-baseline.json)
records the cooled units before opening to rethread the filament. The
[preflight](preflight.json) records the printer states after rethreading.

The [launch record](launch.json) identifies the accepted job, selected hotends,
material slots and calibration options. The [readiness reading](ready.json)
records the idle printers and stopped dryers before submission.
