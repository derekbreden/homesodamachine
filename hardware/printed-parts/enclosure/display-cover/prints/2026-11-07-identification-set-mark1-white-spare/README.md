# Identification set with a spare white hotend

White PETG uses an available replacement hotend on Mark One. The reviewed
[identification-set archive](../2026-11-06-identification-set-mark1-z000/HSM-identification-Mark1-z000.gcode.3mf)
provides the same geometry and toolpaths with no Z offset on the glued Engineering Plate.
The launch record identifies the selected hotends, material slots and printer job.

The [preceding physical result](../2026-11-06-identification-set-mark1-z000/drying/physical-result.json)
records the repeated overload and removed white hotend.

The [physical result](physical-result.json) records rough white deposition and a
repeated extrusion-motor overload with the replacement hotend. It includes the
follow-up drying readings and matching Bambu filament links. The cause remains
unconfirmed.

The [closed-AMS baseline](drying/closed-baseline.json) records temperature and
humidity after drying, before opening the lids to rethread the filament.
