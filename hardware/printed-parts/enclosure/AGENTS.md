# Enclosure prints

Apply the [support-removal strategy](enclosure/README.md#support-removal-strategy)
to each printable piece in the enclosure assembly. Keep receiver coupons in the
host's production orientation.

- For the shell, use the [nominal wall section](enclosure/interface/lib.rs) for ordinary
  walls, webs and joint ends. Remove cut remnants and tapered tips that leave thin fins.
  Limit a thinner section to the flexure, cover or feature that requires it.
- For back-top or a rear receiver coupon, use the [back-top print and removal instructions](enclosure/back-top/README.md).
- For rail cavities and handholds, use the [rail support readings](enclosure/README.md#rail-supports).
  For exterior show rounds, follow the [chamfer and layer treatment](enclosure/README.md#print-down-show-rounds).
