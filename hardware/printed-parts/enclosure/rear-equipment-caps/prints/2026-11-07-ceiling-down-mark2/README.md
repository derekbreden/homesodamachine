# Ceiling-down regulator comparison

Mark2 prints the standard pointed cover and taller pointed cover, each with its
complete matching receiver. The receiver coupons print ceiling-down in the
production back-top layer direction. The covers stand on their production axial
ends. Each part uses its ordinary layer schedule, without a priming tower.

[job.json](job.json) identifies the exact native archive, settings, source meshes,
emitted cooling intervals and support reading. [bridge-anchors.json](bridge-anchors.json)
reads the catch bridge endpoints against the preceding model section. The receiver
bridges span between solid end shoulders with localized cooling; their pockets
contain no support paths. Physical bridge finish, insertion effort and durability
await Derek's review.
