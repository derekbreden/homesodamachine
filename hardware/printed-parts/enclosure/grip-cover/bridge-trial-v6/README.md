# Grip receiver bridge trial records

The [physical acceptance](../physical-acceptance.json) records Derek's support-removal
and assembled-fit observations for the identified receiver and cover articles.
The narrow end-wing slot roofs print as bridges; the broad lifting ceilings use
tree supports.

The [H2C preflight](h2c/preflight.json) and [Mark2 preflight](mark2/preflight.json)
bind each receiver's source mesh, native archive, print settings and measured
coverage. Their [H2C](h2c/launch.json) and [Mark2](mark2/launch.json) launch receipts
identify the submitted jobs. The support audits describe the actual support
roads, slot clearance and bridge paths:

- [H2C support audit](h2c/support-audit.json) and [preview](h2c/preview.png).
- [Mark2 support audit](mark2/support-audit.json) and [preview](mark2/preview.png).
