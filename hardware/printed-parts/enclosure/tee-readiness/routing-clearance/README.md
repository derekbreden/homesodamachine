## Reproduce

Use one retained `build_pack` native cache containing `frames.json` and the named BREP
bodies. The route check requires the actual `g-ganen-pump` scene and a freshly generated
cap. It rejects an old pump cache and does not remove an interfering anchor to pass.

```sh
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_flank_clearance.py --pack-cache /path/to/current-pack
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_fluid14_anchor.py
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_fluid14_anchor.py --native-step hardware/printed-parts/cold-core/foam-cap/foam-cap-lid-top.step --output hardware/printed-parts/enclosure/tee-readiness/routing-clearance/dependency-regeneration/fluid14-native-lid.json
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_fluid14_route.py --pack-cache /path/to/current-pack
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_fluid14_currentness.py
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_fluid18_route.py --pack-cache /path/to/current-pack --neighbor-cache /path/to/current-route-neighbors
tools/cad-venv/bin/python hardware/printed-parts/enclosure/tee-readiness/routing-clearance/verify_cold_core_unaffected.py
```
