# Shop storage

Job storage uses standard Gridfinity interfaces and job-specific vertical
inserts. A job tower occupies a small bench footprint, docks to an ordinary
Gridfinity baseplate, and presents the tools above the consumables. The top is
itself a Gridfinity baseplate, so the job rack can be changed without replacing
the tower below it.

The shared geometry comes from
[`cq-gridfinity`](https://github.com/michaelgale/cq-gridfinity), not from a local
copy of the Gridfinity mating profiles. Tool and consumable holders use public
product envelopes and generous open sockets where a close contour is not
available.

## Towers

- [`jst-crimping/`](jst-crimping/) — upright wire spool, XH consumables drawer,
  and head-down rack for the JST hand tools.
