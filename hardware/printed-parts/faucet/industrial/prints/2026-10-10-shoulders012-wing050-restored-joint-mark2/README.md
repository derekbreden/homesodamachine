# Complete Industrial faucet — Mark2

The authorized five-part project contains the base, tip, Industrial display cover,
counter plate and lever. It has the 70° female-base/male-tip joint and smooth
shared tube/ribbon passages, 0.12 mm base shoulder bands and 0.50 mm longer cover
wings. Ordinary model layers are 0.24 mm above the 0.20 mm first bed layer.
Tree (auto), Default style and automatic support sections are retained.

The [preparation](preparation.json) binds the current source meshes and prepared
project. Native slicing and review are in progress; no import or Send has occurred.
