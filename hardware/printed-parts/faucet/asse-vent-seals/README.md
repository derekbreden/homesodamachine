# Retained sealed-cavity parts

The current faucet uses the [unsealed overflow drip pocket](../vent-qualification/README.md).
Its drain needs no TPU bung, gasket or insertion tool. Factory assembly is
described in [faucet shell assembly](../faucet-shell/ASSEMBLY.md).

This directory preserves the two-bung sealed-cavity articles and their native
print/assembly evidence. The [manifest](manifest.json),
[tool motion record](tool-motion-check.json),
[tool bearing record](tool-bearing-check.json) and
[ribbon review](ribbon-native-check.json) apply only to the exact sealed-cavity
source and artifact hashes they identify. They do not describe the current
unsealed tip, qualify its physical discharge or authorize a print.
