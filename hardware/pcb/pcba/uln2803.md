# Step 2 — ULN2803A → SOIC-18

U4/U5 are bare ULN2803A octal Darlington sink drivers in SOIC-18 (300 mil), `C845537`
(see [`jlcpcb-parts.md`](jlcpcb-parts.md)). Footprint + pin map live in
[`pcba_parts.tsx`](pcba_parts.tsx); placement and nets in [`pcba.tsx`](pcba.tsx).

The SOIC pin order matches the plug-in module's two header rows, so the swap kept every net:
`.U4 > .IN1..IN8 / .GND / .COM / .OUT1..OUT8` are the same labels the `U4I`/`U4O` rows
carried, just on one chip instead of two rows. IN1-IN8 + GND sit on the −X side (toward the
MCP GPA banks), COM + OUT8-OUT1 on the +X side (toward the manifold JSTs), so the
GPA → IN → OUT → valve flow stays left-to-right at default rotation.

Power pins ride the planes like everything else: GND (pin 9, an SMD pad) auto-stitches to the
bottom GND plane (see [`plane-stitching.md`](plane-stitching.md)); COM (pin 10) lands on
net.V12 under the top V12 island, same layer, direct. The 16 signal connections autoroute.

Firmware mapping is unchanged. Inside the chip channel _j_ is IN_j → OUT_j, and the netlist
still wires GPA_k → IN_{8−k} and OUT_n → J.OUT_n, so MCP GPA bit _k_ still actuates the same
manifold pin it did on the carrier — `valve-control.mmd` needs no re-sync.
