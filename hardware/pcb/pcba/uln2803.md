# U4/U5 — TBD62083 octal DMOS sink drivers (SOIC-18, 300 mil)

U4/U5 are Toshiba **TBD62083AFWG** octal DMOS sink drivers in SOIC-18 (300 mil), `C165895`
(see [`jlcpcb-parts.md`](jlcpcb-parts.md)). Each channel is a ~325 mΩ low-side DMOS switch — a
pin- and footprint-compatible replacement for the ULN2803A Darlington that shared this land,
dissipating far less at the ≤0.5 A/channel valve current (no ~1.1–1.5 V Darlington drop), so
U4/U5 — the board's hottest parts, with U5 ch5 also sinking the always-on condenser fan — run
cooler for the same job. Footprint + pin map live in [`parts.tsx`](parts.tsx) (the `Tbd62083`
wrapper on `imports/TBD62083AFWG_EL`); placement and nets in [`pcba.tsx`](pcba.tsx).

Pin map: `.U4/.U5 > .IN1..IN8 / .GND / .COM / .OUT1..OUT8`. IN1-IN8 + GND sit on the −X side
(toward the MCP GPA banks), COM + OUT8-OUT1 on the +X side (toward the manifold JSTs), so the
GPA → IN → OUT → valve flow stays left-to-right at default rotation. Physical pins: 1-8 IN1-IN8,
9 GND, 10 COM, 11-18 OUT8-OUT1.

COM (pin 10) is the common cathode of the internal freewheel diodes — tied to the 12 V load
supply exactly like the ULN's flyback common — so the drop-in kept the same net. Power pins ride
the planes like everything else: GND (pin 9, an SMD pad) auto-stitches to the bottom GND plane
(see [`plane-stitching.md`](plane-stitching.md)); COM (pin 10) lands on net.V12 under the top
V12 island, same layer, direct. The 16 signal connections (GPA → IN, OUT → J) are hand-routed
`pcbPath` traces like the rest of the board (see [`hand-routing.md`](hand-routing.md)).

Firmware mapping is unchanged by the DMOS swap. Inside the chip channel _j_ is IN_j → OUT_j, and
the netlist still wires GPA_k → IN_{8−k} and OUT_n → J.OUT_n, so MCP GPA bit _k_ still actuates
the same manifold pin the pin map assigns — `valve-control.mmd` needs no re-sync.
