# Drill and weld bench sheets

Three illustrated Letter sheets: drill the blind register, prepare the closure
weld, then hold the rotation pedal and pull the laser trigger.

[The authoring and printing instructions](../assembly/letter/README.md) describe
the source requirements, print layout, qualification scope and hand-run builder.
The PDF here is the same document delivered under `output/pdf/`; its cover and
sidecar put it on the [document shelf](https://homesodamachine.com/drawings).
