# Blinded native modeling

The [isolated comparison](https://homesodamachine.com/labs/solidcraft/identification?trial=blind) shows independently authored SolidCraft and Rust identification chips and an actual historical lettering request withheld during their construction.

The builders receive the same complete earlier interfaces and original vector outlines, with no inherited chat. Their permitted inputs exclude later production geometry, existing studies, project history and the other implementation. The custodian seals the historical request before modeling. Accepted baseline sources and outputs are hashed and frozen before each author receives the same release packet.

The comparison retains separate source archives for the frozen and edited models. SolidCraft documents contain native editable history and evaluated bodies. Their Python authoring program generates native primitives and sketches. The Rust program constructs the geometry with the ordinary hsm APIs. Both retain material-separated models and fused printable exteriors.

Extract a source archive beneath `.cache/runs/<run-name>` in this checkout. The archive preserves the packet and builder-directory relationship used by its included authoring command. Native `.sc` containers also open directly in SolidCraft. The runtime and kernel revisions, input hashes, request commitment, freeze hashes, source changes and separate observations live in the comparison's `results.json`.

The recorded trial uses original artwork supplied equally to both authors. It evaluates constructing and changing the native geometry from those curves; it does not evaluate font creation or layout. The access restrictions are procedural in the shared filesystem, and the authors report no forbidden-information exposure. The trial is an individual historical case; it establishes neither general performance nor physical print qualification.

The website uses its existing shared renderer for both implementations. Authoring, tool recovery, model repairs, engine/export work, independent review and common website publication retain separate observations. Nothing in this study joins a normal build or commit check, changes a production part, or launches a print.
