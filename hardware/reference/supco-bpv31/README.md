# Supco BPV31 bullet piercing valve

The Parts model shows the assembled valve with its service cap on. Local X
runs along the bare saddle bore through the origin. The flare points toward
negative Y and the screw heads face positive Z. The optional tube adapters
and wrench are loose installation hardware.

Supco specifies the tube range, male flare and zinc body. Its patent drawings
show the screw layout, saddle split and flare orientation. The photos set the
casting, cap and screw proportions. Those dimensions are estimates in
[`model.rs`](model.rs), and the model represents the visible exterior.
