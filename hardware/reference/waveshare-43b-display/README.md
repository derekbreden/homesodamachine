# Waveshare ESP32-S3-Touch-LCD-4.3B display — reference solid

A keep-out envelope for the Waveshare ESP32-S3-Touch-LCD-4.3B (Amazon
B0D925SBYF), the 4.3" 800×480 capacitive-touch config + interaction display
set into the enclosure front panel (front-panel README §1, `hardware/bom.md`
§1). A purchased part, not a printed one — the model is for the front-panel
cutout and layout, not a manufacturing drawing.

Two stacked rectangular blocks sharing one X–Y center, from caliper
measurements:

| Block | Size (X × Y × Z) | Part |
|---|---|---|
| Box | [106](BODY_WIDTH) × [69](BODY_HEIGHT) × [17](BODY_DEPTH) | main body — PCB, display module, rear components |
| Box | [112.5](BEZEL_WIDTH) × [75](BEZEL_HEIGHT) × [1](BEZEL_DEPTH) | bezel — front cover-glass / touch-panel plate |

## Coordinate convention

- **X** = width — lateral, across the screen
- **Y** = height — up the screen
- **Z** = depth — screen-normal; +Z toward the screen (user side)

Origin is the center of the footprint in X–Y; both blocks are centered on
it. Z = 0 at the device's bounding back (body rear). The body spans
Z 0 → [17](BODY_DEPTH); the bezel caps the front, Z [17](BODY_DEPTH) → [18](TOTAL_DEPTH),
overhanging the body on every side — [3.25](BEZEL_OVERHANG_X) per side in X,
[3](BEZEL_OVERHANG_Y) per side in Y.

Overall envelope: [112.5](BEZEL_WIDTH) (X) × [75](BEZEL_HEIGHT) (Y) × [18](TOTAL_DEPTH) (Z) mm.
