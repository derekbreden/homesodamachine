# Female Faston receptacle

The catalog model represents the mid-width open-barrel receptacle in the Bstenky DDD622 kit specified by the [bill of materials](../../ledger/bom.md). The rolled metal contact, stamped openings and separate tapered insulating boot follow the [kit photographs](https://www.ebay.com/itm/287603994533). The clear boot is rendered in pale gray and sits over the crimp, as in the product photograph.

The published dimensions for the comparable DJ622-D4.8B in the [Fengdeng terminal catalog](https://static2.xunxiang.site/uploads/sites/120/2021/11/d82668a192d74772e7e7f09d15dd55d5.pdf) set the contact width and length in [the model source](model.rs). The photos set the sleeve proportions and visible details. The [pump capture](../kamoer-kphm400/scan-evidence.json) shows its solder tabs. The receptacle width is provisional until physically matched as specified in the [pump harness procedure](../../assembly/harnesses/j13.md).
