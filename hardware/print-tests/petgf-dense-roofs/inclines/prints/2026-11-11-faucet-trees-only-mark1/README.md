The complete lower faucet coupon uses Slim trees under the dense nonplanar
interface. A perimeter follows the suspended rim and meets the bed-backed
tangent. Each heat-insert shoulder and blind pilot roof is bridged. The
[path review](path-review.json) reads the actual rim backing and insert
clearance. The [print job](print-job.json) records the executable and
printer acceptance.
