# Faucet curve gap trial

This print tests a larger top contact gap on the failed Slim faucet article.
The [job record](print-job.json) owns the settings, source archive, printer
calibration, hashes and estimate. Dense roof generation and the model bead paths
retain the failed trial's geometry. The [separation reading](separation.json)
compares commanded bead envelopes. The [physical result](physical-result/physical-result.json)
records easier removal with the roof mats joined, and essentially unchanged
underside finish.

The [launch](launch.json) records printer acceptance. The
[first-layer status](first-layer-status.json) records the printer reporting
deposition without an error; it is telemetry, not a camera inspection.
