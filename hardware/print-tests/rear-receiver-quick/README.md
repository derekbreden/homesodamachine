# Backed flow-meter shoulder

The Mark2 specimen is the recessed aft shoulder of the flow-meter receiver, printed in the enclosure’s roof-down direction. A permanent slope from the flank carries its protruding edge. The taper near the step provides room for the meter cap. Compare the underside with the long, loose strands shown beside the installed Pisco in the four-notch coupon. Run a fingertip along the edge and look at how it meets the step; repeated handling reveals strands that lift off an apparently firm surface.
