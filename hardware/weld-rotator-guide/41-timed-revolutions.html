  1. Stay in mode jog. Set speed 5.
  2. Line the index mark up with a fixed point on the base — a corner, a bench hole, anything that does not move.
  3. Hold the pedal and start the stopwatch as the mark passes the point. Stop it as the mark comes back round.
  4. Repeat at speed 8 and speed 15.
  5. Listen while each one runs.
Gate — ±1% on all three, and no noise

Each time lands inside its accept column. A stall, a skipped tooth, or an audible step loss fails the drive — and it fails it here, at zero load, which means it will certainly fail under a 2 kg vessel.
