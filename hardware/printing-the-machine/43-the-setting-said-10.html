Speed

The setting said 10.
The lip ran at 16.

A slicer keeps more than one speed for the same wall. Where the wall leans out, Bambu Studio takes its speed from a separate overhang table. Two trials that were meant to print a curling lip slowly printed it faster than the trial before them.

Seen in Bambu TPU 85A · Mark 1 · right 0.6 mm nozzle · sliced in Bambu StudioNot tried in: other plastics, whose files have the same table

The lip of the elbow, layer by layer1 Layer 21, 14.4 mm/s: faint curl already. 2 Layer 27, 16.4 mm/s: “about the same as 2 prints ago”.

“Maybe we can try slowing down that outer edge more?”
DEREK · 13 OCTOBER 2026, AFTER THE FIRST CURL

So the outer wall went from 25 mm/s to 10 and the elbow was printed again. The edges looked different for a moment, then the same.

“Oh, maybe it is curling. I guess I’m not interested in a midpoint when the difference in those numbers is 10 13 17 so small and the difference I’m observing is maybe non existent upon reflection.”
DEREK · LOOKING AT THE SECOND PRINT

He was right. The file had not slowed the lip at all.

Why

The outer wall speed covers beads that sit squarely on the layer below. A bead that hangs partly over air takes its speed from the overhang table, and two bands of that table still held stock values. The slicer blended them with the wall speed, then stretched each layer to its minimum time of {{tpu-elbow:/slow_down_layer_time/0}} seconds. With the plain walls slower, that slowdown was shared out differently, and the lip came out faster.

The fix

Set those bands to the wall speed, then read the file. In the corrected file all 13,728 outer-wall moves from layer 2 to the top run at 10.0 mm/s.

Before you print

Do not trust the speed box. Pick the feature that matters and read the speed the sliced file commands there, layer by layer. In this repository that is hsm-gcode speeds FILE --layers 17-33 --at leftmost.

Still openWhether a true 10 mm/s cures the curl in Bambu 85A is not known. The corrected Bambu file was never sent as a single elbow. The first lips printed at a real 10 were a different brand, an hour later.
