Finish + ship · 04/5The appliance

Bottom-up pack, top-down unboxing — the quick start is met first, the front face first.

  1. Stand the carton, TOP arrow up — bottom end-cap in, recess up; kit per the table.
  2. Lower the appliance rear-to-REAR — the umbilical row faces the marked rear wall; top end-cap mates the corners + funnel surround.
  3. Fill the side voids — faucet bag coiled 8–12″, the faucet toward carton TOP; kit box docs face up. Wedge both with foam corner-blocks.
  4. Lay the quick start on top — face up, across everything.
  5. Seal — short flaps then long; kraft tape across all three top seams, then the bottom. A $7,500 carton telegraphs care.
