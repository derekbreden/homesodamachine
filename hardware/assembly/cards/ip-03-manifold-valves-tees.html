IP-03

Flavor manifold
— valves and tees

Internal plumbing · 03/6Kitchen edition

Build to the truth table: fluid-topology.md names every valve (V-A…V-J), every junction (Y-A…Y-H), every segment — the manifold matches it segment-for-segment.

  1. Lay out all ten Beduan valves with their inlet/outlet legends visible — NC solenoids, flow I→O only.
  2. Lay out the junctions between them in topology positions: 2 PP2308E Y-dividers (Y-E, Y-H) + 6 PP0208E Tees (Y-A, Y-B, Y-C, Y-D, Y-F, Y-G).
  3. Pre-cut all 28 tube segments from the reel to the topology tables — square-cut both ends, and tag each with masking tape by segment number.
Every junction is tube-hung. No divider and no tee seats on a tray — the trays carry valves only, so all eight hang on their own tubing. Y-D / Y-G, the pump-discharge tees, wait for IP-04. Bench sub-assembly vs in-place build is an open item; this card assumes bench.
Stock + tools Mudder cutter · masking tape · 1/4″ LLDPE reel
Two-valve tray — the manifold's one printed cradle, 5 off, all the same part. Four corner sockets and a port saddle per seat, nothing else on it; each seat is symmetric, so a valve drops in either way round — set flow by its arrow, not by the tray. Five pairs: V-E·V-F (Y-E) · V-H·V-I (Y-H) · V-A·V-B and V-C·V-D, which share Y-A and Y-B between them, a Tee on each column · V-G·V-J (the nozzle gates, no shared junction).
Done when10 valves + 8 junctions laid out to the truth table; 28 segments cut square, tagged by number — ready to build outward (IP-04).
