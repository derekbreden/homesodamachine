FC-02

Flash the three ESP32s

Commissioning · 02/5Kitchen edition

One wrapper, three MCUs, strict order — base controller first, then both display heads.

  1. Base first — controller PCBA. USB-C into J14 (west edge); the CH340C auto-resets EN/IO0 into download mode.
  2. Watch it land — build OK, upload 100 %, boot banner + fw_version.h build ID at 115200 baud.
  3. Config display next — the 4.3B enumerates native USB-CDC on boot. Flash, then confirm the LVGL splash on the 800×480 panel.
  4. Faucet display last — the 1.47″ on the gooseneck, same CDC. Flavor UI up; touch-toggle waits for FC-03.
PersistentLog build failure? Fix the sibling-repo placement — the wrapper pre-flights the symlink and prints the fix.
