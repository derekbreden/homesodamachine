The cold kit

At the bottom of the install kit, in its own bag, is a tube cutter and a set of foam sleeves, with a short guide of their own. Nothing in that bag is part of this installation. It is there for afterwards, if you want to shorten the run to the faucet to your own cabinet's length and sleeve the whole of it — a shorter, better-insulated run pours colder. Open it once everything here is done and working.

The little printed tool

Keep the collet press. Any 1/4-inch push fitting in this system comes apart with it and goes back together by hand, so it is the tool for the filter, for the funnel's drain, and for the day you move house.
