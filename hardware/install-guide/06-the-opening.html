Before you start

The opening

One hole, 1-3/8 inches across, through the countertop. It is the only cutting this installation asks for, and it happens before install day.

The Quick Start opens with the faucet already above a prepared hole, because cutting that hole is not part of the afternoon. On laminate it is a hole saw. On granite, quartz or any other stone it is a diamond core bit, wet, and it is usually a countertop fabricator's job — the same trade that cut the sink out.

If you are having the counter drilled by someone else, this is all they need:

Give the fabricator
Diameter1-3/8 in (34.9 mm), the standard single-hole faucet opening
CountOne
SlabAnything from 3/4 in to 1-1/2 in thick
WhereWherever you want the faucet, with the cabinet below it clear enough to reach — see the next page
Mind this

Nothing about the hole is measured on install day and nothing is aimed at. The faucet finds its own place in it. What matters is only that the hole exists, and that it is the right size.
