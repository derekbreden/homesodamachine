Rehearse one-axis probing

The simulator defaults allow the complete command sequence to be checked before a controller is connected. Its fit qualifies software execution only.

  1. Begin with X only. Use the simulator jog directory printed by the second command as SIM_JOG_DIR.
  2. Inspect trial bounds and engagement counts in jog-plan.json. Each request is ≤640 counts; twice engagement stays ≥400 default maximum dead-band.
  3. Read the held-out validation report. Rehearsal motion and pixel accuracy are separate from loaded hardware acceptance.
$GP_PY $GP_OBS/observe.py learn plan --out "$GP_SETUP/jog-plan.json" --axes X
$GP_PY $GP_OBS/observe.py learn jog --plan "$GP_SETUP/jog-plan.json" --features "$GP_SETUP/features.json" --root "$GP_SIM"
$GP_PY $GP_OBS/observe.py learn fit SIM_JOG_DIR --features "$GP_SETUP/features.json" --out "$GP_SIM/analysis"
$GP_PY $GP_OBS/observe.py learn validate SIM_JOG_DIR --model "$GP_SIM/analysis/model.json" --split "$GP_SIM/analysis/split.json" --out "$GP_SIM/analysis"
Ready when

The simulated session completes, fit writes its model/split, and validation-report.txt starts VALIDATION: PASS. An invalid plan or failed software rehearsal stops the hardware step. Fix its files/model before connecting motor power.
