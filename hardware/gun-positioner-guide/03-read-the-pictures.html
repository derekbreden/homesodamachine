Read the pictures

Each operation shows the part you add and the assembly that receives it. The ready check states what lets you continue.

  1. Sort hardware into the ADD tray before starting the operation.
  2. Use the matching part IDs in the fabrication drawings and print filenames.
  3. Read the ready check before installing a part that would hide the joint.
  4. Print the book on Letter at actual size. Pictures are not drilling templates.
Ready when

The plate drawings and cut list set the dimensions. Electrical figures show named connections; their layout does not set physical connector pin order. If a part ID or connection differs, stop and reconcile it with the governing manifest before assembling that joint.
