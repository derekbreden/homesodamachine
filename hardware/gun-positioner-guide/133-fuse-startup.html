Qualify the selected cold-start fuses

The adapter, buck, VM capacitors, fan and fuses are tested as one actual configuration before motor coupling or reference.

AddNo new parts
Tools / setupExisting voltmeter · contact temperature tool · selected installed fuses
  1. Keep host USB connected and motor plugs disconnected through 30 brick cold starts; log each boot token, fuse and voltage result.
  2. Perform 30 MOTOR POWER cycles, waiting for switched VM below 1 V between cycles.
  3. Record actual fuse types/ratings, brick hiccups, Pico resets and holder/connection temperature.
  4. Repeat this gate after changing a supply, buck, VM capacitor or fuse.
Ready when

Every start is normal with USB preserving the Pico boot token: no fuse opening, brick hiccup, unexpected reset or overheated holder/connection. Any failed start changes fuse time-current selection or requires engineered inrush limiting. Do not silently raise a fuse rating; correct the actual combination and repeat.

Added electrolytics plus the six modules’ C1/C2 total nominal 1190 µF, about 0.343 J at 24 V, before fan/buck capacitance. This functional check does not measure millisecond peaks or overshoot.
