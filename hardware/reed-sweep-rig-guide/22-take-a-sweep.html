Run the rig

Take a complete sweep

Choose endpoints that let the magnet pass every fitted reed in both directions.

  1. Clear loose steel. Try sweep <from> <to> in the console. Use millimeters from the tab to the sled's near face, within the range shown by status.
  2. Close the console. From the repository root, run the command below with your port, sled, station assignments and measured values in millimeters. Use a new output directory for each run.
  3. The log reader homes the sled and repeats the sweep. Press Ctrl-C to stop it. Keep the float and tube IDs and the measured wall gap with raw.log and sweep.json.
hsm-peripheral reed-sweep --port <port> --sled nominal \
  --reeds 2=A,3=B --play <roller-play> --glass <glass-length> \
  --from <from> --to <to> --output <new-run-directory>
A complete record

Check that each leg starts and ends in the log and every named reed has a complete open-close-open window in both directions. If an endpoint cuts off a window, adjust it within verified travel and rerun.
