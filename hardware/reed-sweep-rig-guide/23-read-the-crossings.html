Set reed heights from the sweep

Combine each reed's closure position with the float's measured waterline to calculate where the reed goes.

  1. Run NOMINAL, NEAR and FAR in separate directories. Check clearance and home again each time you change sleds.
  2. For each reed, read the closure and release positions and their spread in sweep.json. Retain separate activation windows and keep raw.log for replay.
  3. Use the rising closure for full (pump off) and the falling closure for empty (pump on). For each threshold, use the signed offsets below to calculate the reed center height. Record the result and the release position in the reed calibration record.

Reed center height = target liquid height + a − d

a = magnet center height minus liquid surface height, measured with the float in liquid.
d = magnet center height minus reed center height, from the directional closure in sweep.json.

Check in liquid before fixing the reeds

In the intended vessel, confirm both crossings repeat and occur before their respective travel stops. Apply the acceptance limits in the float calibration procedure before soldering fixed columns or printing the final bridge.
