Check the wiring

Verify the inputs on USB

Leave the adapter and motor unplugged. Use the ESP32 console to check the reeds and home switch before the carriage can move.

Load the rig controller

Use pio device list to find the port that appears when you connect the ESP32 over USB. From the repository root, run these commands with that port in place of <port>.

pio run -e reed_rig -t upload --upload-port <port>
pio device monitor -e reed_rig --port <port> --echo

Check reeds and home switch

  1. Lift the roller out of its slot and move the loaded sled by hand. Confirm that the console reports an R line at each closure and release, with the correct station number. Lower the roller back into its slot.
  2. Send status with the lever free. Press and hold it, then send status again. The console should read home free, then home pressed.
  3. If those states are reversed, read the pin level in status with the lever held. Send homelevel low for a low pin or homelevel high for a high pin. Repeat the lever check after any polarity change or reset, then leave the lever free.
Home switch ready

With the lever released, status reports the home input free and the controller has registered a switch change since power-up.
