Check the wiring

Prove the inputs on USB

Leave the adapter and motor unplugged. Use the ESP32 console to check the reeds and home switch before the carriage can move.

Load the rig controller

Find the board's port with hsm-peripheral boards. Run the commands below from the checkout. The monitor reads its baud rate from the rig's PlatformIO target.

Watch the reed inputs

Lift the roller free and move the loaded sled along the tube by hand. Each wired station reports an R line on closure and release. Put the roller back in its slot once the check is done.

pio run -e reed_rig -t upload --upload-port <port>
pio device monitor -e reed_rig --port <port> --echo

Watch the home input

  1. Send status with the lever free. Press and hold it, then send status again. The console should read home free, then home pressed.
  2. If those states are reversed, set homelevel low for a pin that goes low when pressed or homelevel high for one that goes high.
  3. Repeat the press and release after any polarity change or controller reset. Leave the lever free.
Both inputs are proven

Each intended reed changes on its assigned station and the home input follows the real lever. The endstop's light is a local indication. Use the console reading to confirm what the ESP32 sees.
