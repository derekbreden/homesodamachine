Check the wiring

Set the drive current

Start at the low reference voltage specified in the rig procedure. The motor stays unplugged while you measure.

  1. Disconnect both supplies. Seat the driver as on page 15 and reconnect the logic header. Leave the motor lead out.
  2. Connect USB first, then the adapter. Measure VREF and adjust in small increments with an insulated tool to about half a volt. Read the meter after each adjustment.
  3. Unplug the adapter and USB before plugging in the motor lead.
Ready for a short jog

The initial reference is measured and recorded. Recheck the carrier and switch if any reading disagrees with the schematic. Keep the motor adapter within reach for first motion.
