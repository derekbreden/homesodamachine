Prepare · build guide

Start both dryers tonight

Use the two different AMS units already in the shop. The cycles run at the same time; the longer PETG cycle sets the overnight schedule.

ASA Aero

80 °C
8 hours

AMS HT · White 46100

PETG Translucent

65 °C
12 hours

AMS 2 Pro · Clear 32101

  1. Load the ASA Aero into an AMS HT and the PETG Translucent into an AMS 2 Pro. Connect the AMS HT's own power cable. Remove PLA and other lower-temperature spools from that AMS 2 Pro.
  2. Latch both lids. Set static drying to the temperatures and durations above, then start both cycles.
  3. Complete both cycles before printing. Leave each spool in the same closed AMS for storage and printing.
Keep the material names exact

ASA Aero is the white foaming material. Bambu PETG Translucent Clear (32101) is the shell material, the same clear filament used for the flavor reservoirs. Select those names in the supplied projects.
